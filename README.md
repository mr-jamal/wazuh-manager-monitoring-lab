# Wazuh Manager Monitoring Lab

## Overview
A hands-on Security Operations Center (SOC) lab using Wazuh on Kali Linux to monitor manager health and investigate Cloudflare security events.

## Objectives
- Monitor Wazuh Manager service status.
- Ingest Cloudflare security events.
- Inspect alerts in Wazuh Threat Hunting.
- Demonstrate custom detection rule `100500`.

## Key Result
Successfully verified that the Wazuh Manager service was running and observed a Level 8 alert generated by custom rule `100500` for a Cloudflare blocked-request lab event.

## Disclaimer
This project demonstrates lab-based security monitoring and detection. The displayed event is test data, not evidence of a confirmed real-world attack.
